# კოდის აგებულება

## პრინციპები

- **ბიბლიოთეკების და build-ის გარეშე** — სუფთა HTML, CSS და JavaScript მოდულები. ბრაუზერი პირდაპირ კითხულობს, რაც მარტივს ხდის ცვლილებებს და Live Server-ით მუშაობას.
- **კომპონენტები** — საიტის ყოველი ნაწილი ცალკე საქაღალდეა, სამი ფაილით.
- **თარგმანები ცალკე** — ტექსტი კოდში არ წერია; ყველაფერი `src/i18n/`-შია, ახალი ენის დამატება = ერთი ფაილი.
- **ერთიანი დიზაინი** — ფერები, შრიფტები, ღილაკები ერთ ადგილას (`src/styles/`).

## კომპონენტი

```
src/components/hero/
  hero.html         მარკაპი (ერთი ძირითადი ელემენტი)
  hero.module.css   სტილი — კლასები კომპონენტის სახელით (BEM: hero__title, hero__row--modes)
  hero.js           ქცევა: export function init(root) { ... }
```

`index.html`-ში კომპონენტი ისმება ასე: `<div data-component="hero"></div>`.
`src/main.js` ჩატვირთავს სამივე ფაილს, ჩასვამს მარკაპს, თარგმნის და გამოიძახებს `init(root)`-ს.
კომპონენტს შეუძლია შიგნით სხვა კომპონენტი ჩასვას (მაგ. `site-header` → `lang-switcher`).

**ახალი კომპონენტი:** შექმენი საქაღალდე სამი ფაილით და ჩასვი `<div data-component="...">` სადაც გინდა.

⚠️ **Live Server:** ის ყოველ .html ფაილში ჩასვამს თავის სკრიპტს და პასუხს ჭრის. ამიტომ ყოველი კომპონენტის .html ფაილი მთავრდება `</body>` ტეგით — სკრიპტი ჯდება მის წინ, ბოლოში, და `main.js` მას შლის. ახალ კომპონენტშიც დაამატე ეს ბოლო ხაზები.

## კომპონენტებს შორის კავშირი — `src/core/state.js`

კომპონენტები ერთმანეთს პირდაპირ არ იძახებენ; ცვლიან და უსმენენ საერთო მდგომარეობას:

```js
import { on, set } from '../../core/state.js';
set('lang', 'en');                      // lang-switcher: ენა შეიცვალა
on('lang', code => { ... });            // ნებისმიერი კომპონენტი: რეაგირებს
```

| გასაღები | ვინ ცვლის | ვინ უსმენს |
|---|---|---|
| `lang` | state (პირველად — IP-ით ან შენახული არჩევანით), lang-switcher (`chooseLang`) | i18n (მთელი გვერდის თარგმნა), hero (სიები), lang-switcher |
| `homeLang` | state (IP-ით დადგენილი „სახლის“ ენა) | hero, lang-switcher — ეს ენა სიებში პირველია |
| `langChanging` | state (`chooseLang`, ენის შეცვლამდე) | hero (იმახსოვრებს ბლოკების ადგილს → FLIP ანიმაცია .3 წმ), scene (იმახსოვრებს ფონის ადგილს — ენის შეცვლისას ფონი არ ინაცვლებს; ზომის შეცვლისას თავიდან ითვლება) |
| `heroBottom` | hero (ტექსტის ბლოკის ქვედა კიდე პიქსელებში — ენის, შრიფტის ან ზომის შეცვლისას) | scene (ტელეფონზე სცენა ტექსტის ქვეშ იწყება) |
| `startButton` | scene (ითვლის, სად დადგეს ღილაკი) | start-button |
| `sceneReady` | scene (ფონი პირველად დაიხატა) | main.js — ჩატვირთვის ეკრანი ქრება და გვერდი ერთად ჩნდება (მაქს. 4 წმ ლოდინი) |
| `screen` | core/screens.js (`openGame` — „დაიწყე“, `openHome` — „მთავარი“, ბრაუზერის „უკან“) | game (პირველ ჩვენებაზე ხატავს რუკას) |
| `quizOpen` | game (რუკების დარბაზი, „სწავლა“), quick-quiz (დახურვა) | quick-quiz — დროშების ტესტის ფანჯარა |
| `gold` | quick-quiz (სწორ პასუხზე +10) | game — ოქროს მრიცხველი. **მხოლოდ მეხსიერებაში**, ბრაუზერში არ ინახება |

## თარგმანები — `src/core/i18n.js`

```html
<h1 data-i18n-html="hero.title"></h1>               <!-- ტექსტი HTML-ით -->
<span data-i18n="header.login"></span>              <!-- უბრალო ტექსტი -->
<a data-i18n-attr="aria-label:header.login"></a>    <!-- ატრიბუტი -->
```

JS-ში: `t('hero.subjects')`. თუ არჩეულ ენაზე თარგმანი არ არის, ჩანს ქართული.
რვავე სწავლების ენა თარგმნილია: `src/i18n/` — `ka`, `en`, `tr`, `hy`, `az`, `ru`, `kk`, `uz` (ერთნაირი გასაღებები; თუ გასაღები აკლია, ჩანს ინგლისური, შემდეგ ქართული).
**ახალი ენა:** `src/i18n/ka.js` → დააკოპირე, თარგმნე, დაამატე `DICTS`-ში, `LANGUAGES`-ში და `COUNTRY_LANG`-ში (`src/i18n/languages.js`).
**შრიფტები:** ქართულ Noto-ს კირილიცა და სომხური არ აქვს, ამიტომ `index.html` Noto Sans/Serif-ის ზოგად და სომხურ ვარიანტებსაც ტვირთავს;
Google Fonts ამას unicode-range-ით აწვდის — ბრაუზერი მხოლოდ გვერდზე არსებულ დამწერლობას ტვირთავს (`src/styles/tokens.css`).

## ენა IP-ით — `src/core/geo.js`

პირველ ვიზიტზე ენა სტუმრის ქვეყნით ირჩევა: ქვეყანა → ენა (`COUNTRY_LANG`, `languages.js`); თუ ამ ენის თარგმანი ჯერ არ გვაქვს
ან ქვეყანა ვერ დადგინდა — ინგლისური. ეს ენა („სახლის“, `homeLang`) სიებში პირველია და არჩეულია.
ქვეყნის დადგენის რიგი: `?country=TR` (ტესტი) → შენახული შედეგი (7 დღე) → IP: ოთხი წყარო ერთდროულად, იგებს პირველი —
`/api/geo` (ჩვენი სერვერი, CDN-ის სათაურით: Cloudflare `CF-IPCountry`, Vercel `x-vercel-ip-country`; ლოკალურად — `tools/dev-server.mjs`),
`api.country.is`, `get.geojs.io`, Cloudflare `cdn-cgi/trace` (ლიმიტი 2 წმ) → **დროის სარტყელი** (`Asia/Tbilisi` → GE; ვერ დაიბლოკება) → ბრაუზერის ენა.
⚠️ სამი გარე სერვისი მესამე მხარეა (სტუმრის IP იქ მიდის) — საიტის CDN-ზე გაშვებისას საკმარისია `/api/geo`; კონფიდენციალურობის პოლიტიკაში აღსანიშნავია.

**სტუმრის პარამეტრები — `src/core/prefs.js`.** რასაც სტუმარი თვითონ ცვლის (ჯერ — ენა, `chooseLang`), ინახება ბრაუზერში (`getPref` / `setPref`)
და საიტის დახურვისა და ხელახლა გახსნის შემდეგაც იგივე დახვდება; ენის შემთხვევაში IP-ს სჭარბობს. ახალი პარამეტრიც (ხმა, თემა...) აქ ინახება.

| ფაილი | რა ხატავს |

| `nature.js` | ქედები (თხემის განათებით), ბორცვები, გზები, ნაძვები და მუხები, ღრუბლები, ვულკანი, ნაპერწკლები |

**ორი ფენა (სისწრაფისთვის).** ნახატში ~15 000 ელემენტია; თუ ის ერთ SVG-ში დგას, ყოველი მოციმციმე ვარსკვლავი მთელ ნახატს
თავიდან ახატვინებს (გაზომვით: მთავარი ნაკადი წამში ~640 მწ-ს ხარჯავდა უმოქმედო გვერდზე). ამიტომ `scene.js`:
1. უძრავ ნაწილს (`bg`) სურათად ტვირთავს და **ერთხელ ხატავს `<canvas>`-ზე** — შედეგი ჩვეულებრივი ბიტმაპია, თავიდან მხოლოდ ეკრანის ზომის შეცვლისას იხატება;
2. მოძრავ ნაწილებს (`fx`: დროშები, ალი, ნაპერწკლები, ვარსკვლავების ნაწილი, გვირგვინი, რგოლი — სულ ~150 ელემენტი) ცალკე პატარა SVG-ში სვამს ზემოდან.
სახატავი ფუნქცია მოძრავ ფრაგმენტს `anim(frag, wrap)`-ს აწვდის, სადაც `wrap` არის გახსნილი `<g transform=...>` ტეგები, რომლებშიც ის იხატებოდა — ასე ზედა ფენაში
იგივე ადგილას ჯდება. ნათებები (`glow`) უძრავ ფენაში რჩება, რადგან ზემოდან დახატული სილუეტებს გადაფარავდა.
ორივე ფენა ერთი და იმავე ჩარჩოთი (viewBox) თავსდება ეკრანზე; ყოველი მოძრავი ელემენტი ყოველ კადრზე სტილის გადათვლას ითხოვს, ამიტომ მათი რაოდენობა შეზღუდულია.

**უსაფრთხო ზონა.** კომპიუტერზე ტექსტის ბლოკი (`.hero__inner`) ეკრანის ~52%-ს არ სცდება, რომ ხმლის კვარცხლბეკს არ შეეხოს (1366×768-ზე სხვაგვარად ფარავდა);
ტელეფონზე სცენა ტექსტის ქვეშ იწყება — hero აქვეყნებს `heroBottom`-ს, scene მას უსმენს (DOM-ს პირდაპირ არ კითხულობს).

ნახატი დროებითია (კოდით დახატული). ნამდვილი გრაფიკის მოსვლისას ფუნქციები შეიცვლება სურათებით (`public/`), დანარჩენი კოდი უცვლელი დარჩება.

## ლოგო — `public/logo.svg`, `public/favicon.svg`

დროებითი ლოგო, სანამ თამაშის სახელი აირჩევა: ჰორიზონტალური ხმალი (სცენის ცენტრალური ობიექტი) გვირგვინით.
პირის ზედა ნახევარი სიკეთისაა (ვერცხლი, ოქროს წარწერა), ქვედა — ბოროტების (შავი ფოლადი, ცეცხლოვანი წარწერა).
`logo.svg` (128×40) — ზედა ზოლში; `favicon.svg` (64×64) — იგივე ხმალი მუქ კვადრატზე, წარწერის გარეშე.
ორივე გენერირდება: `node tools/gen-logo.mjs` (წარწერა `runes.js`-ის ანბანით) — ფაილებს ხელით ნუ შეცვლი, შეცვალე გენერატორი.

## უკვე არსებული დამატებითი ნაწილები

- **ეკრანები — `src/core/screens.js`** — მთავარი გვერდი (`<div class="landing">` index.html-ში) და თამაში. „დაიწყე“ → `openGame()`:
