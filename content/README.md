# სასწავლო შინაარსი (ტესტები)

სწავლა თამაშში **ტესტების ფორმით** მიმდინარეობს: ყოველი თემა არის კითხვების ნაკრები. სწორი პასუხი სამეფოს აძლიერებს, ბრძოლაში კი იგებს ის, ვინც სწორად და სწრაფად პასუხობს.

## სტრუქტურა

```
content/
  schema/question.schema.json      ← ფაილის ფორმატის აღწერა (JSON Schema) — რედაქტორი ამით ამოწმებს შეცდომებს
  subjects/
    english/<თემა>.json            ← ინგლისური (ასევე spanish/, german/, french/)
    geography/<თემა>.json          ← გეოგრაფია
```

ერთი ფაილი = ერთი თემა (მაგ. `capitals-europe.json`). `*.sample.json` — ნიმუშებია, ყველა ტიპის კითხვით.
მოგვიანებით ეს ფაილები ჩაიტვირთება მონაცემთა ბაზაში (`database/schema.sql`, ცხრილები `topics`, `questions`).

## ტექსტები და ენები

ყოველი ტექსტი იწერება სწავლების ენებზე: `{ "ka": "...", "en": "...", "ru": "..." }`.
**ქართული (`ka`) სავალდებულოა**, დანარჩენი ენები ემატება თანდათან (თუ თარგმანი არ არის, ჩანს ქართული).
სიტყვა, რომელიც არ ითარგმნება (მაგ. ინგლისური „Hello“), იწერება უბრალო სტრიქონად.

## კითხვების ტიპები

| type | რა არის | `answer`-ის ფორმა |
|---|---|---|
| `single_choice` | ერთი სწორი პასუხი რამდენიმედან | ვარიანტის id: `"a"` |
| `multiple_choice` | რამდენიმე სწორი პასუხი | id-ების სია: `["a", "c"]` |
| `true_false` | მართალია / მცდარია | `true` ან `false` |
| `fill_blank` | ჩაწერე გამოტოვებული სიტყვა | სიტყვა; დამატებით `accept` — დასაშვები ვარიანტები |
| `match_pairs` | დააწყვილე (სიტყვა — თარგმანი) | წყვილები: `[["cat", "კატა"], ...]` |
| `order_words` | ააწყვე წინადადება სწორი რიგით | სიტყვები სწორი რიგით |
| `listen_choose` | მოუსმინე და აირჩიე | ვარიანტის id (`media.audio` — ხმა) |
| `flag_pick` | აირჩიე სწორი დროშა | ვარიანტის id (ვარიანტებს აქვს `country`) |
| `map_pick` | რუკაზე აჩვენე ქვეყანა (გეოგრაფიული მდებარეობა) | ქვეყნის კოდი: `"IT"` |
| `image_choice` | სურათი → სწორი პასუხი (მაგ. ღირსშესანიშნაობა) | ვარიანტის id |

არასავალდებულო ველები: `explanation` (ახსნა პასუხის შემდეგ), `timeLimitSec` (დრო ბრძოლაში), `points` (ქულა, ნაგულისხმევად 10), `level` (თემის სირთულე 1–10).

## რეჟიმები

- **ოფლაინ (ბოტთან)** — ვარჯიში ნებისმიერ დროს, ინტერნეტის გარეშეც (თემები ინახება მოწყობილობაზე).
- **ონლაინ** — ბრძოლა მეგობრებთან და სხვა მოთამაშეებთან: ორივე ერთსა და იმავე კითხვებს პასუხობს, იგებს სწორი და სწრაფი პასუხი.
